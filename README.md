# WorkShop College — Website Concept

A responsive, single-page college website built with HTML, CSS, and vanilla JavaScript.

## Features

- Responsive navigation for desktop and mobile
- College introduction and program cards
- Campus-life gallery, student story, and news sections
- Admissions enquiry modal with client-side demo feedback
- Accessible labels, keyboard escape-to-close, reduced-motion support
- No build tools or package installation required

## Preview locally

1. Download or clone this repository.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages

1. Open the repository's **Settings** tab.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for GitHub Pages to publish the site. The Pages panel will show the live URL.

## Before using this for a real college

This is a polished demo/template, not an official college website. Replace the sample name, contact details, programs, campus imagery, and any generic claims with verified information. The admissions form is front-end only and **does not send or store submissions**; connect it to a secure backend or trusted form service before accepting real enquiries. Do not collect personal data until privacy and security requirements are in place.

## Technology

- HTML5
- CSS3 (responsive layout, custom properties, media queries)
- Vanilla JavaScript
- Google Fonts and Unsplash-hosted demo imagery
